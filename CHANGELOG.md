# Changelog

All notable changes to this extension are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-28

First release.

### Added

- **Animated pixel-art companion** in the Activity Bar with ten states: idle,
  thinking, typing, coding, reviewing, success, error, waiting, paused and
  sleeping.
- **Three characters**: Byte (a purple and cyan robotic cat, default), Pixel
  (a floating ghost) and Bugsy (a green bug robot). Characters are discovered
  from `media/sprites/*/manifest.json`, so new ones need no code changes.
- **Three environments**: Cozy Desk, Night Studio and Pixel Garden.
- **Activity detection** built on a modular adapter architecture:
  - A Copilot adapter that observes `vscode.lm.onDidChangeChatModels` and
    Copilot's presence in the extension host.
  - A language-model tool adapter that registers a real `vscode.lm` tool, giving
    a genuinely model-driven signal when the tool is invoked.
  - An editor adapter that reports document edits, saves and focus changes as
    *inferred* activity.
  - A manual adapter for user-driven states.
- **Detection confidence is always visible.** Every activity is labelled
  `direct`, `inferred` or `manual`, so a generic editor edit is never presented
  as a detected Copilot request.
- **No fabricated progress percentage.** No progress value is displayed
  anywhere, because the VS Code API exposes no real one.
- **Activity timeline** with sanitized labels, sources and confidence values.
  Optionally persisted to local extension storage.
- **Diagnostics panel** listing each adapter's availability and the reason when
  one is unavailable.
- **Status bar item** mirroring the current state.
- **Ten commands** for showing, hiding and toggling the companion, choosing a
  character, environment or manual state, clearing history, resetting settings
  and showing diagnostics.
- **Sixteen settings** covering the character, environment, animation speed and
  size, reduced motion, status bar, timeline, inferred activity, manual mode,
  timeouts and history retention.
- **Security**: restrictive webview CSP with a per-render nonce, restricted
  `localResourceRoots`, validated messages in both directions, no `eval`, no
  remote scripts and no network requests. The extension works fully offline.
- **Tests**: unit tests for the state machine, activity manager, animation
  controller and message protocol, plus integration tests that run inside a
  real Extension Development Host.
- **Procedural asset pipeline**: sprites and environments are generated by
  `npm run assets` using a dependency-free PNG encoder.
